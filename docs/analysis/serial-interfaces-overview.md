## 概述

本文档总结 StarryOS 中与串口相关的所有接口，除了主要的 UART（uart_16550）之外，还包括：

| 接口类型 | 硬件基础 | 实现位置 |用途 |
|----------|----------|----------|------|
| **Console (N_TTY)** | axhal::console → UART | `kernel/src/pseudofs/dev/tty/ntty.rs` | 系统控制台，用户交互 |
| **PTY (伪终端)** | 无硬件，纯软件 ringbuf | `kernel/src/pseudofs/dev/tty/pty.rs` | 终端模拟器（SSH、tmux等） |
| **vsock (virtio-vsock)** | virtio socket 设备 | `axnet-ng/src/vsock/` + `axdriver_virtio/socket.rs` |虚拟机与主机 socket 通信 |

## 1. Console (N_TTY)

### 1.1 架构

```
用户态 → /dev/console → N_TTY (Tty<Console, Console>)
                         ↓
                    axhal::console::read_bytes/write_bytes
                         ↓
                    axplat-riscv64-qemu-virt::console.rs
                         ↓
                    MmioSerialPort (UART 16550)
```

### 1.2 核心代码

**文件**: `kernel/src/pseudofs/dev/tty/ntty.rs`

```rust
pub type NTtyDriver = Tty<Console, Console>;

#[derive(Clone, Copy)]
pub struct Console;
impl TtyRead for Console {
    fn read(&mut self, buf: &mut [u8]) -> usize {
        axhal::console::read_bytes(buf)
    }
}
impl TtyWrite for Console {
    fn write(&self, buf: &[u8]) {
        axhal::console::write_bytes(buf);
    }
}
```

### 1.3 中断驱动模式

```rust
// ntty.rs
process_mode: if let Some(irq) = axhal::console::irq_num() {
    ProcessMode::External(Box::new(move |waker| register_irq_waker(irq, &waker)))
} else {
    ProcessMode::Manual
}
```

**关键**: Console 使用 `register_irq_waker` 实现中断驱动，这与我们计划的 AsyncUart 模式完全一致。

### 1.4 tty-reader copier 任务

**文件**: `kernel/src/pseudofs/dev/tty/terminal/ldisc.rs`

```rust
// ProcessMode::External 模式下spawn 后台任务
axtask::spawn_with_name(
    move || {
        block_on(poll_fn(|cx| {
            while reader.poll() {// 处理输入
                poll_rx.wake();
            }
            poll_tx.register(cx.waker());
            register(cx.waker().clone());  // 注册中断唤醒
            Poll::Pending
        }))
    },
    "tty-reader".into(),
);
```

**这正是 ADR-008 设计的 ISR → AtomicWaker → copier 任务模型的参考实现！**

## 2. PTY (伪终端)

### 2.1 概念

PTY (Pseudo Terminal) 是纯软件实现的终端，不涉及任何硬件串口：
- **Master端**: `/dev/ptmx` — 终端模拟器（如 SSH、tmux）使用
- **Slave端**: `/dev/pts/N` — shell 等程序使用

### 2.2 核心代码

**文件**: `kernel/src/pseudofs/dev/tty/pty.rs`

```rust
pub type PtyDriver = Tty<PtyReader, PtyWriter>;

// 使用 ringbuf 作为数据通道
type Buffer = Arc<HeapRb<u8>>;

pub struct PtyReader(Cons<Buffer>);
pub struct PtyWriter(Arc<SpinNoPreempt<Prod<Buffer>>>, Arc<PollSet>);

pub(crate) fn create_pty_pair() -> (Arc<PtyDriver>, Arc<PtyDriver>) {
    let master_to_slave = Arc::new(HeapRb::new(PTY_BUF_SIZE));
    let slave_to_master = Arc::new(HeapRb::new(PTY_BUF_SIZE));
    // ... 创建 master 和 slave
}
```

### 2.3 数据流

```
Master写 → master_to_slave ringbuf → Slave 读
Slave 写 → slave_to_master ringbuf → Master 读
```

### 2.4 与 AsyncUart 的关系

PTY 的 ringbuf + PollSet 模式与 AsyncUart 的 rx_buf/tx_buf + PollSet 设计一致，可作为参考。

## 3. vsock (virtio-vsock)

### 3.1 概念

vsock 是 virtio 规范中的 socket 设备，用于虚拟机与主机之间的高效通信：
- **不是传统串口** — 是 socket API（AF_VSOCK）
- **基于 virtqueue** — DMA 传输，性能远高于模拟 UART
- **用途**: 虚拟机内部程序与主机程序通信（如 guest agent）

### 3.2 架构

```
用户态 → socket(AF_VSOCK) → VsockSocket → axnet-ng/vsock/
                                   ↓
                            VsockStreamTransport
                                   ↓
                            axdriver_virtio/socket.rs → VirtIOSocket
                                   ↓
                            virtio-drivers::device::socket → virtqueue
```

### 3.3 Feature 启用路径

```
Cargo.toml (顶层):
  qemu = ["starry-kernel/vsock"]

kernel/Cargo.toml:
  vsock = ["axfeat/vsock"]

axfeat/Cargo.toml:
  vsock = ["axruntime/vsock"]

axruntime/Cargo.toml:
  vsock = ["net-ng", "axnet-ng/vsock"]
```

### 3.4 核心驱动实现

**文件**: `axdriver_virtio-0.1.4-preview.3/src/socket.rs`

```rust
pub struct VirtIoSocketDev<H: Hal, T: Transport> {
    inner: InnerDev<H, T>,  // virtio-drivers::VsockConnectionManager
}

impl VsockDriverOps for VirtIoSocketDev<H, T> {
    fn connect(&mut self, cid: VsockConnId) -> DevResult<()>;
    fn send(&mut self, cid: VsockConnId, buf: &[u8]) -> DevResult<usize>;
    fn recv(&mut self, cid: VsockConnId, buf: &mut [u8]) -> DevResult<usize>;
    fn disconnect(&mut self, cid: VsockConnId) -> DevResult<()>;
}
```

### 3.5 与 AsyncUart 的关系

vsock 不属于串口范畴，但展示了：
- **virtio transport 的 DMA 模式** — 可参考用于 M6 DMA 探索
- **连接管理器模式** — `VsockConnectionManager` 管理多连接

## 4. 总结对比

| 特性 | Console (N_TTY) | PTY | vsock | AsyncUart (计划) |
|------|-----------------|-----|-------|------------------|
| 硬件 | UART 16550 | 无 | virtio socket | UART 16550 |
| 数据通道 | axhal::console | ringbuf | virtqueue | ringbuf |
| 中断驱动 | ✅ register_irq_waker | ❌ | ✅ virtqueue kick | ✅ 待实现 |
| copier 任务 | ✅ tty-reader | ❌ | ❌ | ✅ 待实现 |
| API | /dev/console | /dev/pts/N | socket(AF_VSOCK) | /dev/ttyS0 |
|DMA | ❌ | ❌ | ✅ | M6 远期 |

## 5. 关键发现

1. **Console 已实现中断驱动模式** — ntty.rs 的 `ProcessMode::External` 使用 `register_irq_waker`，与 AsyncUart 设计一致
2. **tty-reader copier 是参考实现** — ldisc.rs 中的 `spawn_with_name + poll_fn` 模式可直接复用
3. **PTY ringbuf 模式可参考** — `HeapRb + PollSet` 的组合已验证可行
4. **vsock 不属于串口** — 但展示了 virtio DMA 模式，可用于 M6 探索
